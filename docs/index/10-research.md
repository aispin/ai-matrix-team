# 索引卡 · 10 技术方案调研选型规范（矩阵级）

> 适用所有接入项目。原则一句话：**技术方案先调研选型，按最佳实践目标态一次做到位——不留「先上临时方案、以后再换」的过渡态。**

## 四条要素

1. **一手来源**：调研以官方文档 / 源码 / 规范 / 厂商 API 为准，每条结论附出处 URL；产出落 `docs/<域>/04.research-<模块>.md` 并在 TDD 引用。
2. **备选对比**：选型给 **≥2 备选 + 量化对比**（成本 / 可用性 / 资损 / 复杂度 / 回退难度），明确推荐案与理由；有真实取舍记 ADR。
3. **目标态一次做到位**：工期需要分批时，分批只能是「**同一目标态的实施顺序**」，不许以「临时方案」名义上线偏离目标态的设计。
4. **敞口量化**：涉及**资金 / 安全 / 隐私**的方案必须量化资损或泄露敞口。

**例外**：紧急故障处置（恢复后补调研）· 纯机械化改动（改名 / 格式 / 依赖补丁）。
