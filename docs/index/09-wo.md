# 索引卡 · 09 WO 单（面向 agent 的写单须知）

WO 单的读者是**执行它的 agent**（不是人）——所以只写 agent 需要的信息，越短越省。

| 项 | 要求 |
|---|---|
| 生成 | 重单：`guard wo new --slug <kebab> --level L0|L1|L2 [--paths "a/**,b/**"]`（骨架脚本渲染，只填结论；落盘即自动补表行，`--id <行号>` 可绑定已有行）；**轻任务：`guard wo table add --title <t> --brief <≤30字> [--ref <关联>]` 一行即单（SPEC-20261010-03）** |
| **轻 vs 重** | L0/L1 且不触 C1/C2 → 表格一行即可；**触碰 C1/C2 或验收 L2 → 必挂详情单** `runtime/wo-details/<单号>.md`（强制三字段：路径白名单 / 验证命令 / 回滚方案） |
| **体量** | 主文件 **≤6KB 硬上限**（charter §4A.8）；超限 `guard wo lint` 退出码 5。超了 = 你在写过程叙事 |
| **过程叙事去哪** | 执行流水/讨论往来/收口细节 → 逐条 `guard wo journal --wo <id> --who <角色#呼号> --what "…"`（append-only `.journal.md`；读方按需取增量，禁整读旧文）。⚠ append-only 只属于**台账/流水**：**文档正文**只保留最新真相（不写变更记录、不加修订注释、不把版本号写进文件名；历史去 git 找） |
| §2 白名单 | 只约束**交付物**路径；扩大 → 回团长核准。**流程产物豁免**：本单 §8/§10 勾选、journal、交接单属流程产物，收尾可直接写；台账只经脚本维护 |
| **调研选型** | 涉及技术方案的 TDD/WO 须有调研选型依据：**一手来源附出处** + **≥2 备选量化对比**，按最佳实践目标态一次做到位；缺 → 质检可打回（细则 [`10-research.md`](10-research.md)） |
| §5 验证 | **3–5 条可复制直跑的命令 + 期望结果**；抄来的命令必须先真跑一遍再落单（lint 要求本节含可执行命令） |
| §6 回滚 | 可执行动作（命令/开关/反向迁移），禁写「重新部署上一版」 |
| 状态机 | 表单：`TODO→EXECUTING→VERIFYING→DONE`（`guard wo table start|verify|done|back`；卡 DR `block --dr`）；重单：`DRAFT`→`APPROVED`→`IMPLEMENTING`→`VERIFYING`→`DONE`；卡 DR 用 `BLOCKED_DR` |
| 锁定 | 表单 EXECUTING 即锁定（🔒），其他 agent 不得触碰/抢占 |
| 收口 5 件 | QA 放行 · 收口 commit 带 WO 号（动过共享面，`guard audit` 可验）· 交接单（`guard handoff`，≤15 行）· 释放共享锁 · 归档 `closed/` |
| 验收级别 | L0 直提 / L1 质检代验收 / L2 亲验收（拿不准就高） |

**一句话**：WO = agent 的执行规格。轻任务一行即单（`wo table`），重单才落文件；技术细节在代码里，但**白名单/验证/回滚必须落在详情单**。DONE 即归档：`wo table` 写命令收尾自动把 DONE 行移入月度归档（`archive move` 幂等，可重复跑），活动表只留未完成项。
