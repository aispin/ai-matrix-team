# 索引卡 · 09 WO 单（面向 agent 的写单须知）

WO 单的读者是**执行它的 agent**（不是人）——所以只写 agent 需要的信息，越短越省。

| 项 | 要求 |
|---|---|
| 生成 | `guard wo new --slug <kebab> --level L0|L1|L2 [--paths "a/**,b/**"]`（骨架脚本渲染，只填结论） |
| **体量** | 主文件 **≤6KB 硬上限**（charter §4A.8）；超限 `guard wo lint` 退出码 5。超了 = 你在写过程叙事 |
| **过程叙事去哪** | 执行流水/讨论往来/收口细节 → 逐条 `guard wo journal --wo <id> --who <角色#呼号> --what "…"`（append-only `.journal.md`；读方按需取增量，禁整读旧文） |
| §2 白名单 | 只约束**交付物**路径；扩大 → 回团长核准。**流程产物豁免**：本单 §8/§10 勾选、journal、交接单、`shared-contracts.md` 当日登记属流程产物，收尾可直接写；台账只经脚本维护 |
| §5 验证 | **3–5 条可复制直跑的命令 + 期望结果**；抄来的命令必须先真跑一遍再落单（lint 要求本节含可执行命令） |
| §6 回滚 | 可执行动作（命令/开关/反向迁移），禁写「重新部署上一版」 |
| 状态机 | `DRAFT`→`APPROVED`→`IMPLEMENTING`→`VERIFYING`→`DONE`；卡 DR 用 `BLOCKED_DR` |
| 收口 5 件 | QA 放行 · 契约登记（动过共享面）· 交接单（`guard handoff`，≤15 行）· 释放共享锁 · 归档 `closed/` |
| 验收级别 | L0 直提 / L1 质检代验收 / L2 亲验收（拿不准就高） |

**一句话**：WO = agent 的执行规格（目的/白名单/验证/回滚/DR），其余一切留 journal。
