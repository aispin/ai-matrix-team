## 1. 问题

用户要求「不用我们的模板、出全新设计的设计稿」时，现行规则是否支持、按什么流程走？

## 2. 为什么需要你

我做不了：是否允许脱离既有设计系统出新视觉，属品牌 / 视觉口径（Type 1），须你终裁。
不该替你决定：换品牌色 / 新视觉方向牵动「矩阵品牌一致性」。

## 3. 选项

| 方案 | 代价 | 收益 | 推荐 |
|---|---|---|---|
| 甲 维持现状 | 新视觉只能临时特批，无流程 | 一致性最强 | |
| **乙 模式 A/B/C**：A 延续（默认，渲染优先）· B 视觉换新（授权后手写，禁用渲染器）· C 全新方向（examples 不作起点，创始人终裁） | 多两档规则与授权链 | 常规不放松、新视觉有正规通道；**顺带修掉一处内部矛盾**（出稿规则「配色一律沿用」vs 设计系统「品牌色可指定」） | ✅ |
| 丙 完全放开 | 风格全自由 | 最灵活 | |

## 4. 建议默认值

> 按 **乙** 落地：三档模式 + 铁律适用边界（工程质量类仍强制 / 风格类放宽）+ 矛盾修复。

## 5. 不做的后果 / 超时行为

- 不做：用户提全新设计时设计师只能违规或特批，体验上等同「不支持」。
- BLOCKING 不因超时自动通过（品牌口径不可默认）。

## 6. 影响面
